# Projecte Programació 3 – OpenStreetMap

## Estructura
| Carpeta       | Contingut                                             |
| ------------- | ----------------------------------------------------- |
| `docs/`       | Enunciat, guia i presentació de la Part 1             |
| `mapesOSM/`   | Mapes XML per provar (Petit, Cerdanyola, UAB, Eiffel) |
| `Tasca1-i-2/` | Projecte de pràctica (Tasques 1 i 2, no avaluable)    |
| `Part1/`      | Projecte avaluable: `P3-OSM-VS2022.sln`               |

## Com compilar (Part1)

1. Obrir `Part1/P3-OSM-VS2022.sln` amb Visual Studio 2022 (C++ + C# + .NET 8).
2. Projecte d'inici: `P3-OSM-WPF-2022`.
3. Build i executar.

## On treballem

Només dins de `Part1/P3-OSM-DLL-2022/` (C++). No es toca res de `P3-OSM-WPF-2022`.
Al lliurament a Caronte es copien els `.cpp/.h` d'aquesta carpeta.
